# Alfa 0.2.1 — pantalla y continuidad

14 de octubre de 2026. Ajuste de P02 a partir de la observación del director en móvil. El director informó que el recorrido de prueba funcionó; ese reporte no equivale a mediciones de rendimiento ni pruebas instrumentadas en un dispositivo identificado.

## Causa y cambios

El recuadro provenía del CSS provisional: proporción 1:1, ancho máximo y espacio reservado para cabecera y pie. Ahora el canvas llena el área del navegador, descontando zonas seguras, y usa su altura dinámica. La cámara conserva la transformación original, sin deformar sprites, y un ResizeObserver acompaña cambios del tamaño del canvas. Esto no oculta las barras que controla el navegador.

La primera oleada entrega 12 × 14 = 168 XP. La fórmula de Player utiliza 62 XP para llegar al nivel 2 y otros 101 para llegar al 3. Las dos elecciones representan dos niveles distintos, no dos mejoras concedidas por un mismo nivel. El texto muestra el nivel al que corresponde cada elección.

Al consumir la última elección, Expedition.choose invoca ready: inicia la siguiente oleada o permite explorar la salida si se completó la tercera. No elige automáticamente estadísticas por el jugador. Mantiene la pausa durante la elección y conserva el descanso de 20 s sin elecciones pendientes, con opción de saltarlo.

## Validación y límites

La prueba nueva reprodujo el problema: después de elegir la última carta la fase seguía siendo preparación. Se añadió la continuación y se verifican tanto la fase combate de la segunda oleada como las etiquetas nivel 2/3, doble clic y recorridos completos.

Se comprueban las dimensiones reales del canvas en escritorio y móvil vertical/horizontal, fuente y compilado, además de controles, pausa, segundo plano, extracción, derrota y reinicio. Evidencia: [P02-0.2.1-validation.json](P02-0.2.1-validation.json). Revisión estática adicional por subagente, sin defectos materiales detectados; no se presenta como ejecución.

Entorno Chromium/Linux con táctil emulado. Safari y teléfonos físicos quedan pendientes. Sin medición de FPS. Los recursos y mapas siguen provisionales. Roadmap, GitHub y servicios no se modifican en esta entrega.
