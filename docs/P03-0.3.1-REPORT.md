# Alfa 0.3.1 — una mejora por nivel

14 de octubre de 2026. Se reprodujo el reporte del director con el combate y los recogibles reales en fuente y compilado.

La primera oleada tiene 12 enemigos de 14 XP:168 XP. Player.xpFor entrega62 para alcanzar nivel2 y101 adicionales para alcanzar nivel3. Al cerrar la oleada, Player es nivel3 con5 XP sobrantes y Expedition tiene2 elecciones pendientes. No se observó duplicación de XP ni dos categorías aplicadas por nivel.

La confusión era visual: el HUD ya mostraba el nivel final3, mientras el título de las dos elecciones era el mismo genérico. Ahora cada elección se titula Nivel2 alcanzado o Nivel3 alcanzado, el texto pide UNA mejora para ese nivel y el HUD señala elecciones pendientes. La experiencia y dificultad no cambian. Se añade nextUpgradeLevel al snapshot y un contador upgradesApplied para verificar el número de elecciones válidas; cada llamada aceptada aplica una carta y consume un nivel pendiente.

Prueba tests/p03-levels.py: fuente/compilado PASS. Primer combate natural:12bajas, nivel3,5XP,2pendientes; primera selección:+1categoría,1pendiente; segunda:+1categoría,0pendientes; continúa automáticamente. Pulsar dos veces el mismo botón viejo no gasta el siguiente nivel. Recogible controlado de62XP: nivel2,0XP,1pendiente; otro tick no lo vuelve a conceder.
